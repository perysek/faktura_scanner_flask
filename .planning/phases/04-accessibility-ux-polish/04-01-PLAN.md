In both `templates/errors/404.html` and `templates/errors/500.html`, find the CTA link at line ~103 that currently reads:

```html
<a href="{{ url_for('main.invoices_list') }}" class="btn-refined">
```

Replace the `href` value with a Jinja2 inline conditional that routes based on user role:

```html
<a href="{{ url_for('main.invoices_list' if current_user.is_authenticated and current_user.role == 'accountant' else 'main.dashboard') }}" class="btn-refined">
```

Do NOT change the button text ("Powrót do strony głównej"), the SVG icon, or the `btn-refined` class. Only the `href` attribute value changes.

This works because both error templates extend `base.html`, and Flask-Login injects `current_user` into the Jinja context globally. The `current_user.is_authenticated` check handles the case where the user is not logged in (anonymous user proxy returns False).

Apply the identical change to both 404.html and 500.html.
  </action>
  <verify>
    <automated>grep "main.invoices_list.*accountant.*main.dashboard" templates/errors/404.html && grep "main.invoices_list.*accountant.*main.dashboard" templates/errors/500.html</automated>
