**Step 1: Add sr-only CSS to input.css**

In `static/css/input.css`, find the `@layer utilities { ... }` block (starts at line 103). Add the following two class definitions INSIDE the `@layer utilities` block, after the existing `.scrollbar-thin` rules (after line 118, before the closing `}` on line 119):

```css
  /* Screen-reader-only utility (skip-nav, a11y labels) */
  .sr-only {
      position: absolute;
      width: 1px;
      height: 1px;
      padding: 0;
      margin: -1px;
      overflow: hidden;
      clip: rect(0, 0, 0, 0);
      white-space: nowrap;
      border-width: 0;
  }
  .sr-only-focusable:focus {
      position: static;
      width: auto;
      height: auto;
      padding: 0;
      margin: 0;
      overflow: visible;
      clip: auto;
      white-space: normal;
  }
```

NOTE: Use the class name `.sr-only-focusable` instead of `.focus\:not-sr-only` to avoid Tailwind's backslash-escaped pseudo-class syntax. This is simpler, works without Tailwind's JIT, and the HTML will use `class="sr-only sr-only-focusable"`.

**Step 2: Add skip-nav link to base.html**

In `templates/base.html`, insert a skip-navigation link as the FIRST child of `<body>`, immediately after the opening `<body class="h-full antialiased">` tag (line 24) and BEFORE the `{% if current_user.is_authenticated %}` block (line 25).

Insert this HTML:

```html
    <a href="#main-content" class="sr-only sr-only-focusable" style="position:absolute;z-index:9999;top:0.5rem;left:0.5rem;padding:0.5rem 1rem;background:white;color:var(--color-ink);border-radius:4px;box-shadow:0 2px 8px rgba(0,0,0,0.15);text-decoration:none;font-weight:600;font-size:0.875rem;">
        Przejdź do treści
    </a>
```

The inline `style` attribute on the focused state uses `position:absolute` etc. to override the `.sr-only` clip when focused. This avoids relying on any Tailwind `focus:` variant utilities that may be purged. The `.sr-only` class hides it by default; `.sr-only-focusable:focus` makes it visible when focused.

IMPORTANT: The `login.html` template is standalone (does not extend `base.html`), so it does NOT get the skip-nav link — per user decision.

**Step 3: Rebuild CSS**

Run `npm run build:css` to regenerate `static/css/output.css` with the new `.sr-only` and `.sr-only-focusable` utilities included.

```html

```

IMPORTANT: The `aria-live` attribute goes on the container element that EXISTS in the initial HTML DOM (not dynamically created). The content inside it changes via JavaScript — that is what triggers the screen reader announcement. Do NOT add `aria-live` to `<tbody>` or to dynamically injected elements.
