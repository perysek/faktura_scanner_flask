In `templates/appointments/calendar.html`, find the `showError` function at line ~774:

```javascript
function showError(message) {
    Modals.alert({
        title: 'Błąd',
        message: message,
        type: 'error'
    });
}
```

Replace it with an inline error state that renders in the `#emptyState` container (which lives inside the `.timeline-container` that now has `aria-live="polite"` from Plan 02). This way the error is announced to screen readers and includes a retry button:

```javascript
function showError(message) {
    emptyState.style.display = 'block';
    emptyState.innerHTML = `
        <svg style="width:48px;height:48px;color:var(--color-error);margin-bottom:0.75rem;" fill="none" viewBox="0 0 24 24" stroke="currentColor">
            <path stroke-linecap="round" stroke-linejoin="round" stroke-width="1.5" d="M12 9v2m0 4h.01m-6.938 4h13.856c1.54 0 2.502-1.667 1.732-3L13.732 4c-.77-1.333-2.694-1.333-3.464 0L3.34 16c-.77 1.333.192 3 1.732 3z" />
        </svg>
        <h3 style="color: var(--color-error); margin-bottom: 0.25rem;">Błąd ładowania</h3>
        <p>${message}</p>
        <button onclick="loadSchedule()" class="refined-btn-secondary" style="margin-top: 1rem;">Spróbuj ponownie</button>
    `;
}
```

IMPORTANT NOTES:
- The `emptyState` variable is already declared at line ~323 as `const emptyState = document.getElementById('emptyState');` — no need to redeclare it.
- The `message` parameter passed to `showError` is already a safe string literal from the codebase (`'Nie udało się załadować harmonogramu'` at line ~409), not user input. If you want extra safety, you can use template literal escaping, but the existing code already passes only hardcoded Polish strings.
- The retry button calls `loadSchedule()` which is the same function that loaded the data initially.
- The `Modals.alert()` call is REMOVED entirely — the inline error in `#emptyState` replaces the modal approach. This is more accessible because the `aria-live` region on `.timeline-container` will announce the error state change.
