```python
class BaseRepository:
    _columns: str = '*'
    _soft_delete: bool = False

    def _fetch_one(self, query: str, params: tuple = ()) -> Optional[Any]: ...
    def _fetch_all(self, query: str, params: tuple = ()) -> List[Any]: ...
    def _execute(self, query: str, params: tuple = ()) -> Any: ...
    def get_by_id(self, id: int) -> Optional[Any]:
        soft = " AND is_deleted = FALSE" if self._soft_delete else ""
        query = f"SELECT {self._columns} FROM {self.table_name} WHERE id = %s{soft}"
    def get_all(self) -> List[Any]:
        soft = " WHERE is_deleted = FALSE" if self._soft_delete else ""
        query = f"SELECT {self._columns} FROM {self.table_name}{soft} ORDER BY id DESC"
```

**In `repositories/invoice_repository.py`, add `AND is_deleted = FALSE` to these 8 methods:**

1. **`find_by_invoice_number`** (line ~135): Change query from:
   ```sql
   SELECT * FROM invoices WHERE invoice_number = %s
   ```
   to:
   ```sql
   SELECT * FROM invoices WHERE invoice_number = %s AND is_deleted = FALSE
   ```

2. **`find_by_invoice_number_and_seller`** (line ~138): Add `AND is_deleted = FALSE` to ALL three query branches:
   - NIP branch (line ~163): `WHERE invoice_number = %s AND seller_nip = %s AND is_deleted = FALSE`
   - Name branch (line ~170): `WHERE invoice_number = %s AND seller_name = %s AND is_deleted = FALSE`
   - Fallback branch already calls `find_by_invoice_number` which will be fixed above

3. **`search`** (line ~178): Restructure WHERE to filter first, then match:
   ```sql
   SELECT * FROM invoices
   WHERE is_deleted = FALSE
     AND (seller_name ILIKE %s
      OR invoice_number ILIKE %s
      OR seller_nip ILIKE %s)
   ORDER BY invoice_date DESC
   ```
   Note: The ILIKE conditions must be grouped in parentheses so `is_deleted = FALSE` applies to all rows.

4. **`get_by_date_range`** (line ~190): Add filter:
   ```sql
   SELECT * FROM invoices
   WHERE is_deleted = FALSE
     AND invoice_date BETWEEN %s AND %s
   ORDER BY invoice_date DESC
   ```

5. **`get_by_seller`** (line ~202): Add filter to the CROSS JOIN query:
   ```sql
   SELECT i.* FROM invoices i
   CROSS JOIN (SELECT id, seller_nip FROM sellers WHERE id = %s) s
   WHERE i.is_deleted = FALSE
     AND (i.seller_id = s.id
      OR (
          i.seller_id IS NULL
          AND s.seller_nip IS NOT NULL
          AND regexp_replace(COALESCE(i.seller_nip, ''), '[^0-9]', '', 'g') = s.seller_nip
      ))
   ORDER BY i.invoice_date DESC
   ```

6. **`get_recent`** (line ~250): Add filter:
   ```sql
   SELECT * FROM invoices
   WHERE is_deleted = FALSE
   ORDER BY created_at DESC
   LIMIT %s
   ```

7. **`get_upcoming_payments`** (line ~259): Add filter:
   ```sql
   SELECT * FROM invoices
   WHERE is_deleted = FALSE
     AND status = 'Nieoplacona'
     AND payment_due_date IS NOT NULL
     AND payment_due_date >= CURRENT_DATE
   ORDER BY payment_due_date ASC
   LIMIT %s
   ```

8. **`get_overdue_payments`** (line ~271): Add filter:
   ```sql
   SELECT * FROM invoices
   WHERE is_deleted = FALSE
     AND status = 'Nieoplacona'
     AND payment_due_date IS NOT NULL
     AND payment_due_date < CURRENT_DATE
   ORDER BY payment_due_date ASC
   LIMIT %s
   ```

9. **`get_statistics`** (line ~283): Add `WHERE is_deleted = FALSE` to BOTH sub-queries:
   - `query_basic`: Add `WHERE is_deleted = FALSE` after `FROM invoices`
   - `query_amounts` inner SELECT: Add `WHERE is_deleted = FALSE` after `FROM invoices`
