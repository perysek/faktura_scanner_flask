# Plan 09-01: Connection Pooling + Request Lifecycle

## Goal

Replace raw `psycopg2.connect()` calls with a `ThreadedConnectionPool`, add timeout configuration, health checks, and proper request-scoped lifecycle so connections are never leaked.

## Context

Current state of `config/database.py`:
- `DatabaseConnection.get_connection()` stores a raw `psycopg2.connect()` result in Flask `g.db`
- `get_db_connection()` is a module-level alias used by ~15 repositories
- `close_db_connection()` in `app.py` teardown calls `DatabaseConnection.close_connection()` which does `g.pop('db').close()` — this DESTROYS the connection instead of returning to pool
- `UploadStagingRepository` bypasses Flask `g` entirely, creating standalone connections via `psycopg2.connect(get_database_url())`
- No timeouts configured anywhere (no connect_timeout, no statement_timeout)
- `initialize_database()` creates a one-off connection for schema init — acceptable, runs once at startup

Consumer patterns (must be preserved):
- `BaseRepository._get_conn()` calls `DatabaseConnection.get_connection()` — returns bare connection
- Standalone repos use `with get_db_connection() as conn:` — psycopg2 context manager for transaction scope
- Both patterns must continue working unchanged after pooling is added

## Tasks

### Task 1: Implement ThreadedConnectionPool in config/database.py + update app.py teardown
**Files:** `config/database.py`, `app.py`
**Change:**

In `config/database.py`:
1. Add `from psycopg2.pool import ThreadedConnectionPool` import
2. Add module-level `_pool: Optional[ThreadedConnectionPool] = None` variable
3. Add `initialize_pool()` function that creates the pool:
   - Read env vars: `DB_POOL_MIN` (default 2), `DB_POOL_MAX` (default 10), `DB_CONNECT_TIMEOUT` (default 5 seconds), `DB_STATEMENT_TIMEOUT` (default 30000 ms = 30s)
   - Build DSN from `get_database_url()`
   - Create `ThreadedConnectionPool(minconn, maxconn, dsn, connect_timeout=..., options=f'-c statement_timeout={stmt_timeout}', cursor_factory=RealDictCursor)`
   - Store in module `_pool`
   - Log pool creation: `logging.info(f"Connection pool initialized: min={min}, max={max}")`
4. Add `get_pool() -> ThreadedConnectionPool` function that returns `_pool` (raises RuntimeError if not initialized)
5. Add `close_pool()` function that calls `_pool.closeall()` and sets `_pool = None`
6. Modify `DatabaseConnection.get_connection()`:
   - Instead of `psycopg2.connect(...)`, call `get_pool().getconn()`
   - Before returning, validate connection with a health check: try `conn.cursor().execute('SELECT 1')` in a try/except; if it fails (stale/dead connection), call `get_pool().putconn(conn, close=True)` and `get_pool().getconn()` again
   - Store in `g.db` as before
7. Modify `DatabaseConnection.close_connection()`:
   - Instead of `db.close()`, call `get_pool().putconn(db)` to return connection to pool
   - Wrap in try/except to handle edge cases (pool already closed, connection already returned)
8. Modify `initialize_database()`:
   - Instead of raw `psycopg2.connect()`, call `get_pool().getconn()` and `get_pool().putconn()` when done
   - This means `initialize_pool()` must be called BEFORE `initialize_database()`

In `app.py`:
1. Add `from config.database import initialize_pool, close_pool` import
2. In `create_app()`, call `initialize_pool()` BEFORE `initialize_database()` (move initialize_database after pool init)
3. Update `close_db_connection` teardown — it already calls `DatabaseConnection.close_connection()` which will now putconn. No change needed in teardown itself.
4. Add `@app.teardown_appcontext` is already there — verify it works with putconn.
5. Register an atexit handler or use Flask's app shutdown to call `close_pool()`:
   ```python
   import atexit
   atexit.register(close_pool)
   ```

**Commit:** `feat(09-01): replace raw psycopg2.connect with ThreadedConnectionPool`

### Task 2: Migrate UploadStagingRepository to use shared pool
**File:** `repositories/upload_staging_repository.py`
**Change:**

1. Replace `from config.database import get_database_url` with `from config.database import get_db_connection`
2. Replace `_get_connection()` method body: instead of `psycopg2.connect(get_database_url(), ...)`, call `get_db_connection()` which returns the pooled per-request connection
3. Since UploadStagingRepository uses `conn.commit()` and `conn.close()` explicitly in each method, remove ALL `conn.close()` calls — the teardown hook will return the connection to pool. Keep `conn.commit()` calls.
4. Verify every method: `create()`, `get_by_id()`, `get_all()`, `get_by_original_name()`, `delete()` — each should use `conn = self._get_connection()` without closing.

**Why this matters:** UploadStagingRepository currently creates unbounded standalone connections that bypass both Flask `g` and the pool. Each upload request leaks a connection that is closed after use but never pooled. After this change, it participates in the per-request lifecycle.

**Commit:** `fix(09-01): migrate UploadStagingRepository to shared connection pool`

### Task 3: Add connection pool tests
**File:** `tests/test_connection_pool.py`
**Change:**

Create test file verifying:
1. `test_pool_initialization` — after `initialize_pool()`, `get_pool()` returns a ThreadedConnectionPool instance
2. `test_pool_env_defaults` — when no env vars set, pool uses defaults (min=2, max=10, connect_timeout=5)
3. `test_pool_env_override` — when `DB_POOL_MIN=5`, `DB_POOL_MAX=20` set, pool uses those values
4. `test_get_connection_returns_from_pool` — within Flask app context, `get_db_connection()` returns a connection (mock the pool's getconn)
5. `test_close_connection_returns_to_pool` — `DatabaseConnection.close_connection()` calls putconn, not close
6. `test_health_check_replaces_dead_connection` — if first getconn returns a connection where `SELECT 1` fails, a new connection is obtained
7. `test_upload_staging_uses_shared_connection` — UploadStagingRepository._get_connection returns same connection as get_db_connection

Use `unittest.mock` to mock the pool. Use Flask test app context from conftest.py fixtures.

**Commit:** `test(09-01): add connection pool unit tests`
