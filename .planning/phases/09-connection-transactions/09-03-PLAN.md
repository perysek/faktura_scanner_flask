# Plan 09-03: Dependency Audit

## Goal

Audit all project dependencies for broken installs, outdated packages, and critical updates — apply safe updates to requirements.txt.

## Context

Current requirements.txt has 14 pinned packages. Some are from 2023-2024 and may have critical updates. The audit should:
1. Run `pip check` to find broken dependencies
2. Run `pip list --outdated` to find stale packages
3. Evaluate which updates are safe (patch/minor) vs risky (major)
4. Apply critical updates (security fixes, compatibility) to requirements.txt
5. Document decisions (what was updated, what was deferred)

## Tasks

### Task 1: Audit and update dependencies
**File:** `requirements.txt`
**Change:**

1. Run `pip check` — document any broken dependency reports
2. Run `pip list --outdated --format=json` — capture current vs latest for each package
3. Evaluate each outdated package:
   - **Safe to update (patch/minor):** Apply the update to requirements.txt
   - **Major version jump:** Only update if there are known security issues or breaking compat; otherwise defer with comment
   - **Pinned for reason:** Leave alone (e.g., opencv-python uses >= already)
4. Update requirements.txt with new versions
5. Run `pip check` again after updates to verify no breakage

**Guidelines:**
- Flask 3.x → update to latest 3.x if available (not 4.x)
- psycopg2-binary → update to latest 2.9.x
- Pillow → update to latest (frequent security patches)
- alembic → update to latest 1.x
- Keep >= pins as-is (opencv-python, numpy, PyMuPDF)

**Commit:** `chore(09-03): audit and update project dependencies per MIGR-01`

## Success Criteria
- [ ] `pip check` returns no broken dependencies after update
- [ ] requirements.txt has updated version pins
- [ ] No major version jumps without justification in commit message
