**How to use it:**

```bash
# Set credentials once (or add to .env)
set CALDIS_EMAIL=your@email.com
set CALDIS_PASSWORD=yourpassword

# Import last 90 days (default)
python scripts/import_appointments_from_url.py

# Import specific range, keep the xlsx file
python scripts/import_appointments_from_url.py --date-start 2026-01-01 --date-end 2026-04-29 --keep-xlsx

# Test without touching the DB
python scripts/import_appointments_from_url.py --dry-run
```

**What it does under the hood:**
1. GETs login page → scrapes CSRF token
2. POSTs credentials → verifies session
3. GETs `/Booking` → scrapes fresh CSRF token + all room GUIDs
4. POSTs to `/BookingExport/ExportToXlsx` → downloads xlsx to `assets/temp/`
5. Runs the same `import_file()` + deduplication logic as the Excel script
6. Cleans up the temp file (unless `--keep-xlsx`)
