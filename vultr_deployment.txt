```bash

```

## Krok 3 — Sprawdź aktualny stan migracji

```bash
DATABASE_URL="postgresql://faktura_user:choose_a_strong_password_here@localhost/faktura_db" \
  .venv/bin/alembic current
```

## Krok 4 — Uruchom migracje

```bash
DATABASE_URL="postgresql://faktura_user:choose_a_strong_password_here@localhost/faktura_db" \
  .venv/bin/alembic upgrade head
```

## Krok 5 — Włącz soft delete w kodzie

Po udanej migracji odkomentuj `_soft_delete = True`:

```bash
sed -i 's|# _soft_delete = True  # Enable after running migration e9f0a1b2c3d4|_soft_delete = True|g' \
  repositories/invoice_repository.py \
  repositories/clients/client_repository.py
```

## Krok 6 — Zrestartuj aplikację

```bash
sudo systemctl restart my-way-beauty-salon
sudo systemctl status my-way-beauty-salon
```
