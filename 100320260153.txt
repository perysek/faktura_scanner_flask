● ★ Insight ─────────────────────────────────────
  The get_skills_radar() method handles skills stored as either a JSON dict
  {"skill": rating} or a list [{"skill":..., "rating":...}] — defensive because
  JSON fields in Postgres can be inserted in different shapes by different
  callers. The generate_series trick in trend queries is a PostgreSQL-specific
  feature that ensures zero-fill for months with no data, which is critical for
  chart continuity.
